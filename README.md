# IRIS_CLASSIFICATION
This project demonstrates machine learning classification using the Iris dataset with Logistic Regression. It covers data preprocessing, visualization, model training, and evaluation.

Google Colab Notebook
Run the full notebook here:
https://colab.research.google.com/drive/1-VrG_zD-w1aWbG3qU8VxnNNR9F5RUKgG?usp=sharing
 
Workflow Summary
1. Load dataset using scikit-learn
2. Convert to pandas DataFrame
3. Map numeric labels to species names
4. Visualize using pairplot and heatmap
5. Split data into train/test
6. Apply StandardScaler
7. Train Logistic Regression model
8. Predict and evaluate
 
Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
 
Data Visualization
• Pair Plot – shows species separation 
• Heatmap – highlights correlations, especially between petal features 
 
Model Evaluation
The model is evaluated using:
- Confusion Matrix
- Accuracy Score
- Classification Report
 
Accuracy achieved: **95–98%**
